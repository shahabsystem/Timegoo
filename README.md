# SayClock 4.7 — سخنگوی ساعت فارسی

پروژه بر پایه نسخه 4.6 قبلی توسعه داده شده است.

## قابلیت‌ها
- اعلام فارسی با فایل‌های صوتی موجود و گرد کردن به نزدیک‌ترین ۵ دقیقه
- Ding فقط ۱ تا ۵
- ۷ بازه مستقل زمان‌بندی
- اجرای پس‌زمینه و بازیابی زمان‌بندی بعد از راه‌اندازی مجدد
- شدت و سرعت پخش
- انتخاب تاریخ شمسی یا میلادی
- نوتیفیکیشن دائمی ساعت/تاریخ با تاریخ انتخاب‌شده
- یادآوری روزانه با متن دلخواه
- انتخاب ساعت یادآوری
- تست یادآوری
- انتخاب فایل صوتی دلخواه از حافظه گوشی
- صدای پیش‌فرض یادآوری `reminder_chime.wav`
- ظاهر دارک، رنگ و اندازه فونت
- آیکون جدید در اندازه‌های mdpi تا xxxhdpi
- GitHub Actions برای build خودکار

## نکته درباره صدای یادآوری
برای مرجع صوتی، «New Notification 032» از Pixabay انتخاب شده است که صفحه منبع آن استفاده رایگان تحت Pixabay Content License را اعلام می‌کند:
https://pixabay.com/sound-effects/technology-new-notification-032-480570/

در محیط ساخت این پروژه امکان دریافت مستقیم فایل MP3 از CDN منبع فراهم نبود؛ بنابراین برای اینکه سورس بدون فایل خارجی ناقص نماند، یک چایم کوتاه داخلی (`reminder_chime.wav`) قرار داده شده است. کاربر همچنان می‌تواند از داخل برنامه فایل صوتی خودش را انتخاب کند.

## Build
GitHub Actions از JDK 17 و Gradle 8.7 استفاده می‌کند:
`.github/workflows/android.yml`

در GitHub:
Actions → Android Build → Run workflow

خروجی:
`app/build/outputs/apk/debug/*.apk`

# تايمگو — تايمگو 5.0.0

سخنگوی ساعت فارسی اندروید، مبتنی بر فایل‌های صوتی داخلی.

## قابلیت‌ها
- اعلام خودکار ساعت در ۷ بازه مستقل و قابل تنظیم
- اعلام زمان با دقت ۵ دقیقه و فایل‌های صوتی فارسی موجود پروژه
- انتخاب Ding از بین ۵ صدای داخلی
- تنظیم شدت و سرعت پخش
- تاریخ شمسی و میلادی
- اعلان دائمی ساعت و تاریخ
- اجرای زمان‌بندی پس از روشن شدن/تغییر زمان/منطقه زمانی
- **۵ یادآوری روزانه مستقل**؛ هرکدام با متن، ساعت، فعال/غیرفعال و صدای جداگانه
- اعلام ساعت با **تکان دادن گوشی** هنگام باز بودن برنامه
- فونت YEKAN داخلی و تنظیم اندازه/رنگ ساعت
- بدون وابستگی به کتابخانه خارجی برای قابلیت‌های اصلی

## ساخت APK با GitHub Actions
پس از push به شاخه `main` یا `master`، ورک‌فلو `.github/workflows/android.yml` به‌صورت خودکار اجرا می‌شود.

دو خروجی به عنوان Artifact ساخته می‌شود:
- `debug APK` برای نصب و تست سریع
- `release APK` بدون امضای شخصی، برای مرحله انتشار

برای انتشار عمومی، بهتر است APK نهایی با کلید امضای اختصاصی پروژه در GitHub Secrets امضا شود.

## نکته
قابلیت تکان دادن گوشی عمداً فقط وقتی برنامه در foreground است سنسور را فعال می‌کند تا مصرف باتری و رفتار ناخواسته در پس‌زمینه ایجاد نشود.
